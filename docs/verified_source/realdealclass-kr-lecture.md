## ✅ 주요 학습 목표

- **영어의 95%에 해당하는 거의 모든 문장 구조 이해** [[3]]
- 어휘력 + 문장 구조 + 해석 + 작문 + 듣기 + 섀도잉 + 복습 종합 훈련
- 정확한 듣기 이해, 읽기 해석, 작문 및 스피킹 연습 가능
- 프리토킹 단계 전 영어 기본기를 탄탄하게 다질 수 있음 [[1]]
